\section{Additional Experimental Detail}
\subsection{Original geometry sanity check}
The original mechanism run measured correlation 0.9102 between source cosine similarity and 1-bit Hamming agreement, and 0.9761 between source cosine and a 4-bit negative-$\ell_1$ surrogate over random held-out pairs. These values motivate the low-bit substrate but are not ANN recall guarantees.

\subsection{Storage accounting}
For $D=384$, source FP32 embeddings require 1,536 bytes/item. A packed 4-bit substrate requires 192 bytes/item and a packed 1-bit substrate 48 bytes/item. Current NumPy prototypes store codes in \code{uint8}; all storage claims in the paper refer to the packed systems representation. A unary semantic program with 24 active coordinates and 16 int8 values per coordinate requires 384 table bytes plus coordinate identifiers and an intercept; the main benchmark adds two $16\times16$ pair tables.

\subsection{Mechanism ablations}
The selected ablations reported in the main text are reproduced by the mechanism experiment in the repository; full per-concept and per-configuration outputs are emitted as CSV artifacts.

\subsection{Reproducibility}
The main benchmark is produced by \path{experiments/large_scale_search.py} with \path{configs/large_scale.yaml}. The reported run contains all 44,072 products, seeds 7/17/27, a top-5,000 retrieval pool, 200 fit-generated compound queries per seed, 24 unary and two pair LUTs per concept, and 2,000 bootstrap resamples. The result bundle is \texttt{20260904T100524Z\_8204ed57bf} at Git commit \texttt{fea235e}. It was executed on an NVIDIA A100-SXM4-40GB. Each run writes the configuration, environment manifest, predicate metrics, query definitions, per-query rows, aggregate summaries, paired deltas, and figures. The repository also contains a public Colab launcher for smoke and full reproduction.
