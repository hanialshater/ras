\section{Experimental Setup}
\paragraph{Dataset.} We use Fashion Product Images Small \citep{fashiondataset}. The exploratory mechanism benchmark samples 30k products. The main independent-teacher benchmark uses all 44,072 available products.

\paragraph{Mechanism benchmark.} Product titles are encoded by MiniLM \citep{reimers2019sbert,wang2020minilm} into 384-dimensional normalized vectors. Fourteen structured fields serve as concept labels. Product titles often contain those labels, so this benchmark is intentionally a representation/compiler mechanism test, not a leakage-free latent-semantic benchmark. Results use the original 65/35 train/test split; binary thresholds are fit on train.

\paragraph{Independent semantic teacher.} For the main benchmark, MiniLM title embeddings provide both retrieval and the \rsa substrate. CLIP ViT-B/32 image semantics \citep{radford2021clip} independently define eight latent concepts: minimalist, office-appropriate, technical/sporty, retro, elegant, relaxed, chunky, and quiet luxury. For each seed, the catalog is split strictly into 52\% fit, 13\% calibration, and 35\% test (22,916 / 5,730 / 15,426 products). Seeds 7, 17, and 27 define three independent splits. For each concept, CLIP scores each image against positive and negative prompt sets; a threshold chosen only on the fit split sets 40\% positive prevalence and is frozen for calibration and test. \rsa sees only MiniLM-side features.

\paragraph{Predicate models.} The main \rsa model uses a 384-dimensional orthogonal random rotation, 4-bit quantile bins, 24 unary LUTs, and two $16\times16$ pair LUTs per concept. As a semantic-information ceiling on the same MiniLM representation, we train a class-balanced full-precision logistic linear proxy on the unquantized 384-dimensional vectors. Both \rsa and the linear proxy are scalar-calibrated on the held-out calibration split before composition.

\paragraph{Compound-query generation.} Queries are generated using fit data only; test labels never influence query selection. Each query contains one to three positive latent predicates, optionally one negated latent predicate, and zero to two exact filters drawn from color, category, article type, gender, and master category. Exact-filter combinations must have sufficient fit support, and the complete semantic conjunction must have at least 100 positive fit examples. We sample 200 valid compound queries per split, yielding 600 query--split cases.

\paragraph{Search protocol.} For each query, MiniLM retrieves the top 5,000 held-out test products. Exact constraints are then applied as conventional filters. At each retained fraction $r\in\{1,.5,.4,.3,.2,.1,.05\}$, all methods keep exactly the same number of candidates. The dense baseline orders by query--item cosine similarity. \rsa orders by Eq.~\eqref{eq:composition}; the full-precision proxy composes its calibrated concept logits using the same algebra. An oracle ordering places all teacher-relevant items first and therefore provides a budget-constrained upper bound. Recall and purity are measured against the CLIP-defined semantic conjunction \emph{within the exact-filtered top-5,000 ANN pool}; they are not global catalog recall.

\paragraph{Statistics.} We report means over the 600 query--split cases and 95\% query-level bootstrap intervals from 2,000 resamples. Paired intervals are computed on per-query differences against dense retrieval. Because the three splits share one catalog and one latent vocabulary, these intervals should be read as descriptive uncertainty for this benchmark rather than as 600 fully independent real-world queries.
